# Coldfront brand

- **Idea:** the weather-map cold-front symbol (a line with filled triangles pointing the way it travels) drawn as a rising illness wave that crests and runs into a widening forecast fan (50 % and 80 % bands), as on the site's charts.
- **Files:** `mark.svg` (64×64 mark, three triangles, two bands), `favicon.svg` (simplified: two triangles, one band), `logo.svg` (mark + "Coldfront" wordmark drawn as stroked paths, no font needed). All switch colours via `prefers-color-scheme`.
- **Light:** line/triangles `#1d5fa8`, 50 % band `#7fb0e0`, 80 % band `#b9d3ee`, wordmark `#16202e`.
- **Dark:** line/triangles `#6aa9ec`, 50 % band `#2f5f92`, 80 % band `#22405f` (favicon: `#2f5f92`), wordmark `#e6ebf2`.
- **Meaning:** shape carries the meaning (solid line + triangles vs. light fan), so the marks still work in greyscale.
- **Minimum size:** favicon 16 px; mark 24 px; logo 20 px high. Below 32 px, use `favicon.svg` instead of `mark.svg`.
- **Clear space:** keep at least ¼ of the mark's height free on all sides. Don't recolour, rotate, stretch, outline or add effects. Don't put the mark on busy or mid-blue backgrounds.
